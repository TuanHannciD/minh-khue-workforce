# Nhân sự

`EmployeesController` là HTTP entry POST/PATCH; DTO/Swagger sở hữu wire contract. `EmployeesService` chuẩn hóa tên, kiểm mốc và CAS, rồi ghi trong transaction User → Employee; no-op được chấp nhận vẫn cấp revision mới. `EmployeesRepository` sở hữu SQL date-only và query bảo vệ ô xuyên mọi tháng.

Module khác chỉ dùng [index.ts](index.ts). `EmploymentConsistency.lockEmployees` khóa UUID sorted; `findExcludedCells` kiểm số/F/reminder-only mà không ghi/xóa ô. `readByIds` đọc đúng ID, không lọc membership và không khóa ghi; `listForMonth(tx,start,end)` cho Attendance đọc membership trong cùng transaction snapshot. `LockedEmployee` là shape công khai, không phải Prisma entity. EmployeeDto được export để Swagger attendance tái dùng cùng wire shape; không export repository.

`listForMonth` dùng interval intersection; `employment-date.ts` tính Gregorian/date-only/weekday bằng UTC getters tường minh. HTTP tháng/reconcile và attendance write đã có ở Task5; schema ô migration002 đủ dùng, không migration rỗng mới. Invariant liên bảng cần mọi writer attendance đi qua khóa Employee này. Composition root dùng lại cùng DynamicModule references để tránh đăng ký trùng controller/DB pool.

Từ root worktree với Node24/pnpm12 theo [LOCAL_RUN](../../../../../docs/agent/LOCAL_RUN.md): `pnpm --filter @mkw/api build`, `pnpm --filter @mkw/api test`, `pnpm --filter @mkw/api test:employees`. Integration cần `MKW_EMPLOYEE_CLUSTER_OWNER` trỏ đúng cluster fake Task4 đã xác minh; mỗi lượt tạo DB UUID mới, không reset DB cũ. Suite kiểm migration auth upgrade, HTTP quyền/shape, protection, barriers CAS, snapshot và SQL/client readback.

Task3: public `EmploymentConsistency.readMonthPage(tx,query)` trả MonthEmployeePage với SQL membership/count/filter/clamp/LIMIT/OFFSET; chỉ tối đa25/50 metadata về app. Internal `employee-month-read.ts/buildEmployeeMonthRead` sở hữu parameterized membership/match/order theo pinned `pg17.11-icu67.1-vi-db-authority-v1`; lower tên/query theo ICU vi equivalent rồi literal C, UUID text case-sensitive, order tên collated + ID ASC. Không export Prisma.Sql qua public index. Task4 dùng cùng membership/order cho `listForMonth(tx,start,end)` và fullmonth/Excel; Attendance giữ thứ tự seam, không sort lại tên bằng Intl. Tests page/export đối chiếu fixed DB fixture và perturb copy kết quả seam để bắt resort; perturb chỉ là test ownership, không là thứ tự production.
