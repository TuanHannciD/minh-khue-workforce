# Auth — Task3

HTTP `auth.controller.ts` nhận DTO/Swagger, cookie và request IP do Express xác định (trust proxy mặc định tắt). `auth.service.ts` sở hữu login, `requireSession(request)` và logout; không export credential qua response. Controller chỉ serialize `SessionDto`.

`session.guard.ts` chặn sớm và gắn `AuthenticatedSession` nội bộ. Module nghiệp vụ sau này chỉ import public `index.ts`; mutation phải gọi `SessionAuthorizer.authorizeMutation(tx, credential)` trong cùng `Database.transaction` với ghi dữ liệu, trước Employee locks. Guard HTTP không thay fence này. Infrastructure DB chỉ sở hữu Prisma/transaction (READ COMMITTED, lock timeout3s, transaction10s).

`auth-throttle.ts` là PostgreSQL adapter cho interface ThrottlerStorage; login tiêu thụ đồng thời bucket IP20/phút và username5/15phút theo fixed window, khóa bucket theo hash order. HMAC secret riêng; không giữ raw IP/username trong counter. `password.ts` dùng native Argon2id đúng params G1. DB clock sở hữu expiry, cập nhật lastSeen tối đa mỗi phút, không trượt absolute12h.

`auth-operations.ts` sở hữu thao tác account vận hành. `addAccount` hash bằng helper hiện hành trước một transaction create UUID, dựa username unique constraint, chỉ đổi conflict username thành `ACCOUNT_EXISTS`. `listAccounts` chỉ select username và sắp xếp ASC tại DB. Provision vẫn khóa bảng rỗng và tạo đúng hai User; reset vẫn khóa User UPDATE, thay hash/tăng version/revoke cùng transaction, thiếu User trả `ACCOUNT_NOT_FOUND` và giữ thông báo `existing account` cho consumer cũ. Domain errors ở file này để command không tạo dependency cycle.

`account-command.ts` sở hữu `AccountCommand`, `AccountResult`, validator và dispatcher; public `index.ts` export entry nội bộ này cùng add/list và `AccountOperationError`/`AccountErrorCode`. Không thêm controller/provider hoặc HTTP route. Validator chỉ nhận đúng fields của list/add/reset-password, username1–64 Unicode code points không whitespace; không trim/normalize/case fold. Password dùng `validatePassword` (ít nhất8 code points, tối đa1024 UTF-8 bytes), giữ nguyên spaces. Result chỉ có operation và username(s), trả sau khi transaction promise hoàn tất; lỗi COMMIT/revoke được truyền ra, không log payload/hash/driver error. Đây là domain boundary; compiled CLI và release/container preflight thuộc task kế tiếp, chưa có trong checkpoint Task1.

`scripts/product/auth-cli.mjs` vẫn kiểm allowlist/identity target trước đọc secret và gọi provision/reset trực tiếp. Bản CLI này chỉ cho sandbox Task3; chưa có enrollment target thật. Password qua TTY ẩn hoặc pipe stdin riêng, không argv/env/log. Provision giữ policy username length cũ kể cả whitespace; reset domain tiếp tục hỗ trợ account sandbox cũ, production subset được kiểm ở command. Không role/admin/signup/reset HTTP.

Task1 focused: `pnpm --filter @mkw/api build` rồi `node --test apps/api/test/account-command.test.mjs apps/api/test/auth.unit.test.mjs`. Transaction doubles chỉ kiểm query/domain boundary và chờ COMMIT promise, không chứng minh PostgreSQL concurrency/rollback/session behavior; acceptance DB thật thuộc Task9.

Kiểm chứng: `pnpm --filter @mkw/api test` chạy compiled HTTP/config/native hash; `test:integration` cần `MKW_TEST_CLUSTER_OWNER` và cluster riêng theo LOCAL_RUN. Test-only `protected-probes.mjs` chứng minh guard tháng/write/export qua seam; không tạo API nghiệp vụ sản phẩm. `auth.integration.test.mjs` giữ matrix tuần tự cùng DB mới và hai fixture để quản lý secret/ownership/cleanup; các barrier dựa pg_stat_activity, không sleep.
