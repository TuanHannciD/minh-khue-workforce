## Thiết kế và trust boundaries

- Eligible class mới: **gateway-only**, giữ nguyên exact API image, API runtime container/image/start identity và PostgreSQL image/container. Không migrate, không API restart/startup, không sửa API env, không start/replace DB. Chỉ `compose up --no-deps gateway`. Cùng schema/hash không tự cho phép recovery.
- Build producer không giả định API rebuild cùng source có cùng digest: revision labels/provenance làm digest khác. Chỉ reuse API từ previous verified state sau canonical artifact/run/attempt/digest/source checks, manifest attestation và API source-input fingerprint bằng Git tree. Fingerprint bao gồm toàn bộ đầu vào API Dockerfile, root package/lock/workspace/TS config và deploy controls; Web source/nginx là phần được phép thay. Thay input không biết → build API bình thường, incident-only. Không có policy cũ → build bình thường.
- Canonical artifact chứa build policy và manifest bind checksum policy; policy attestation/manifest ownership giữ nguyên canonical signer. Policy chỉ mô tả bounded release operation, không tự khai báo `verified` side effects hoặc chứng minh không có business-data writes. Remote trusted controls mới là producer runtime receipt: dưới flock, đo API/PG trước/sau, binding operation/SHA/ownership/policy, ghi receipt sau gateway apply và trước health failure. Không có receipt đầy đủ → unknown/incident.
- Consumer recovery kiểm cả canonical build policy lẫn receipt, previous LKG, exact current artifact ownership, runtime identity/schema/migration, fresh restore-verified backup và attestation. Gateway recovery chỉ apply gateway; API/PG identity được đo lại sau recovery. Legacy audit class giữ guard cũ; không dùng self-declaration/hash thay audit. Changed/unknown/missing/forged/stale/interleaved evidence dừng trước rollback mutation.
- Manual `workflow_dispatch` routes (coordinator/deploy/backup/verify/rollback) dùng `production-recovery`, canonical main guard và minimal vars/secrets contract. Push/reusable automatic stages và scheduled backup giữ `production`; auto rollback không cần interactive approval. YAML không tạo reviewers; actual settings Not run.
- Harness local riêng, không spoof hosted-runner guards: task-owned Linux control container/Compose project, loopback ports và project-scoped volumes/networks. Chạy real API/Web/PG, real backup dump/restore verification, production deploy/recovery modules. Chỉ fake GitHub ownership/signing ở external boundary, ghi nhãn evidence. Cleanup chỉ owned labels/resources sau giữ evidence. Không truy cập real server/DB.
