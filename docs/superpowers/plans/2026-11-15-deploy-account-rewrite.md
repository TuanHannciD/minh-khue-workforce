- Mapping production chính xác `api→apiImage`, `gateway→webImage`, `db→postgresImage`; chỉ immutable digests. Dùng `docker compose config --format json`, không parser YAML tự viết.
- Upload vào staging operation-owned; publish release/config/shared backup và mutation dưới **một** server lock. - Migration fail không apply app tiếp, không hứa DB chưa đổi. Config nhiều file không là transaction; receipt ghi phase và uncertainty. SIGKILL/host death có thể thiếu terminal receipt.
- Không production/live GitHub/GHCR/SSH/VPS/settings/secrets/dispatch, push/merge/deploy hoặc dữ liệu thật trong execution local này. Không chạy backup production. Không Kubernetes/blue-green/secret manager/scanner mới từ ví dụ skill.

## Review Focus

1. Unicode/whitespace/quote/backslash trong private input bị truncate, JSON encode sai hoặc lộ secret: Task 2/8 kiểm CLI compiled và shell qua stdin; DB không đổi khi invalid.
2. Concurrent duplicate và lỗi giữa update hash với revoke session: Task 1/9 kiểm unique constraint, COMMIT và rollback thực trên PostgreSQL, cả session còn hiệu lực khi rollback.
3. Service swap/duplicate YAML và stale container selection: Task 3/8 kiểm parser thật, zero apply khi invalid, lock/re-read identity và exec đúng ID một lần.
4. Cùng SHA với backup mới, extra file hoặc hai publisher: Task 4/6 kiểm inventory đầy đủ, staging riêng, lock contention và không overwrite release/shared trước lock.
5. Receipt cùng giây/operation khác mới hơn, failed terminal hoặc interruption giữa hai config publish: Task 5/6 kiểm selection theo operation, phase, không success giả và lỗi gốc không bị lỗi reporting che.
