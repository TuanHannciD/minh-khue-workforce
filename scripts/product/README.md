# Tooling sản phẩm — Task2–3

Root npm scripts giữ pilot; nhóm `product:*` chạy bằng Node24/pnpm12 theo [LOCAL_RUN](../../docs/agent/LOCAL_RUN.md). Hai app có bootstrap và auth/session; chưa có module nhân sự/chấm công.

- `check-boundaries.mjs` đọc tsconfig từng app, tạo đồ thị dependency-cruiser với alias/ESM/type imports, kiểm cycle và chuyển cạnh qua `boundary-rules.mjs`. Ownership bao phủ toàn app root, gồm output/declaration/dependency; cạnh dependency được phân loại rồi mới dừng traversal. Checker xét cả identity thực của graph và đường TypeScript resolve giữ symlink để pnpm store không che đường xuyên app. Public feature/module entry là `index.ts`; import cùng feature dùng đường tương đối. Shared/infrastructure không gọi ngược app/feature/module. Web không dùng server/Prisma, kể cả alias tới package đã resolve. ESLint restricted imports và `lint-boundaries.mjs` bổ sung feedback đường tương đối tại source; graph checker sở hữu kiểm alias/package/symlink đầy đủ. Generated contract trong web vẫn thuộc web, kể cả thư mục tên `api`.
- `generate-contract.mjs` nhận document từ `apps/api/src/openapi.ts` đã compile, canonicalize/format, sinh `contracts/openapi.json` và `apps/web/src/shared/api/generated/schema.d.ts`. Hai output thuộc generator, không sửa tay. `check-contract.mjs` sinh lại vào ignored artifact mới rồi so bytes; `--candidate-dir` chỉ dành fixture deliberate drift.
- `staged-gate.mjs` báo Not run/exit2 cho product E2E và benchmark chưa đến task sở hữu. Integration auth hiện chạy thật bằng `pnpm --filter @mkw/api test:integration`, cần owner record cluster Task3; chưa kiểm nghiệp vụ Task4+.
- `sandbox-target.mjs` kiểm allowlist và identity PostgreSQL thực của sandbox giả Task3. `auth-cli.mjs` provision đúng hai User hoặc reset existing User/revoke sessions, secret TTY ẩn/private stdin; không nhận password argv/env. Cách chạy và giới hạn tại LOCAL_RUN.

Fixtures ở `tests/product-tooling`: import hợp lệ/vi phạm, ESLint, cycle, compiler strict/generated consumer và drift. `pnpm run product:check` kiểm build từng app rồi chạy tooling + web Vitest/Testing Library/session + API bootstrap/auth HTTP/native + boundary/contract. Prisma generated có type-only cycles nội bộ do generator tạo; checker chỉ miễn cycle đó trong đúng generated path, vẫn chặn runtime/manual cycles và import xuyên app. Integration PostgreSQL chạy riêng; browser Task3 dùng build thật và DB mới, chưa là gesture/nghiệp vụ acceptance.

Web alias `@/` khớp Vite/tsconfig. API ESM dùng alias native `#app/*` khớp package imports/tsconfig và `.js` specifier; không cần loader hoặc rewrite sau compile. Test API chạy compiled JS để bắt lỗi ESM/decorator metadata/runtime alias. Không import Prisma/entity qua contract generated.
